# _XavierCodes_ Mod's Wiki

Web estatica para documentar **MCA Social Expansion** y **MCA Expressions**.

## Estructura

- `index.html`: contenido principal de la Wiki.
- `styles.css`: estilos del sitio.
- `script.js`: cambio de idioma y modo claro/oscuro.
- `assets/`: imagenes usadas por la pagina.

## Uso

Abre `index.html` en el navegador o publica la carpeta completa con GitHub Pages.

## Contenido

- Fichas rapidas de ambos mods.
- MCA Social Expansion 0.9.2: cuatro interfaces, retratos persistentes, mensajes espontaneos y respuestas, conversaciones con memoria, familia, regalos, Conocer y recetas.
- MCA Expressions 0.2: cinco gestos, variantes contextuales, reglas de uso y compatibilidad para Forge, NeoForge y Fabric.
- Tabla de compatibilidad de Minecraft 1.20.1, 1.21.1 y 26.2, con las dependencias de cada mod.
- Selector de idioma español/ingles.
- Modo claro/oscuro seleccionable.

## Recursos

Las texturas del espejo proceden de MCA Social Expansion. La receta usa texturas de objetos de Minecraft para representar su distribucion en la mesa de crafteo.
