# _XavierCodes_ Mod's Wiki

Web estatica para documentar **MCA Social Expansion** y **MCA Expressions**.

## Estructura

- `index.html`: contenido principal de la Wiki.
- `styles.css`: estilos del sitio.
- `script.js`: cambio de idioma y modo claro/oscuro.
- `assets/`: imagenes usadas por la pagina.

## Uso

Abre `index.html` en el navegador o publica la carpeta completa con GitHub Pages.

## Contenido

- Fichas rapidas de ambos mods.
- MCA Social Expansion 1.0.x: cinco interfaces, grimorio social, recuerdos duraderos, regalos de NPCs, hitos, ajustes personales, contactos, Conocer y recetas.
- MCA Expressions 0.4.x: diez gestos seleccionables, rueda de categorias, juegos infantiles, iniciativas de NPCs, requisitos y ajustes.
- Forge 1.20.1: parches de compatibilidad SE 1.0.1 y Expressions 0.4.1. Los proyectos 1.21.1 y 26.2 usan SE 1.0 y Expressions 0.4.
- Tabla de compatibilidad de Minecraft 1.20.1, 1.21.1 y 26.2, con las dependencias de cada mod.
- Selector de idioma español/ingles.
- Modo claro/oscuro seleccionable.

## Recursos

Las texturas del espejo y del grimorio proceden de MCA Social Expansion. Las recetas usan texturas de objetos de Minecraft para representar su distribucion en la mesa de crafteo.
